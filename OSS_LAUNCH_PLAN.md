# 700 Blind — OSS Launch Plan

## Positioning

**700 Blind** is a Kiara Lab R&D OSS program for interfaces that remain usable when vision, touch, typing, or continuous attention cannot be assumed.

Public tagline:

> Open-source interaction patterns for accessible, voice-first, low-attention, and human-agent interfaces.

## Phase 0 — Internal validation

- Select six flagship patterns.
- Run each on a real iPhone/simulator.
- Test VoiceOver and Voice Control where applicable.
- Test Dynamic Type and Reduce Motion where applicable.
- Record known failures honestly.
- Attach a Boundary Contract and one research question to every pattern.

## Phase 1 — GitHub launch

Publish:

- README
- Swift Package
- six patterns
- GitHub Pages catalog
- CONTRIBUTING
- issue template
- MIT License

Do not publish unverified PASS claims.

## Phase 2 — Public research loop

For every outside Issue/PR, tag the feedback as one of:

- accessibility failure
- extreme-use failure
- developer ergonomics
- boundary-theory observation
- new research question
- enterprise-specific constraint

Turn recurring feedback into the next R&D sprint.

## Phase 3 — Distribution

- GitHub release tags
- Swift Package Index submission
- optional CodePen analogues
- DocC documentation
- short demo videos
- accessibility community outreach

## Phase 4 — Business bridge

Free:
- components
- experiments
- benchmarks
- reference implementations
- public research notes

Paid / Enterprise:
- audits
- private components
- integration
- organization-specific accessibility patterns
- extreme-environment UX research
- FDE-style deployment

## Success metrics

Do not optimize only for stars.

Track:
- outside developers using a pattern
- accessibility issues discovered
- external PRs / research feedback
- new Boundary Theory hypotheses
- enterprise conversations caused by OSS
- patterns reused inside Kiara products
