# Release Checklist

## Implementation
- [ ] Builds with the current supported Xcode
- [ ] Public API is minimal
- [ ] Native semantics are preferred over custom recreation
- [ ] Failure path exists and is understandable

## Accessibility
- [ ] VoiceOver checked on a real build
- [ ] Voice Control checked where relevant
- [ ] Dynamic Type checked where relevant
- [ ] Reduce Motion checked where relevant
- [ ] Controls have meaningful labels
- [ ] State changes can be understood without vision
- [ ] Errors can be recovered from nonvisually
- [ ] No PASS claim without evidence

## Research
- [ ] Boundary Contract written
- [ ] Known failure case documented
- [ ] Research question stated
- [ ] Dogfood evidence recorded

## Public
- [ ] Demo media contains no confidential data
- [ ] License is compatible
- [ ] README example updated
- [ ] Release notes explain what changed
