# Boundary Theory

Boundary Theory asks where responsibility should sit between a human and an agent.

For each interaction, document:

- **Observe** — Human / Agent / Shared
- **Understand** — Human / Agent / Shared
- **Decide** — Human / Agent / Shared
- **Act** — Human / Agent / Shared
- **Verify** — Human / Agent / Shared

A boundary can change based on risk, confidence, context, reversibility, cost, and user preference.
