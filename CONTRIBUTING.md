# Contributing to 700 Blind

700 Blind is an R&D OSS program for interaction patterns that continue to work when users cannot reliably see, touch, type, or continuously attend to a screen.

## A contribution should include

1. The user constraint or failure mode.
2. A working SwiftUI implementation.
3. Accessibility notes: VoiceOver, Voice Control, Dynamic Type, Reduce Motion.
4. A Human–Agent Boundary contract: Observe / Understand / Decide / Act / Verify.
5. At least one known failure case.
6. A research question or measurable hypothesis.

## Pull requests

Keep changes small and testable. Prefer one interaction pattern per PR.

Do not claim accessibility conformance that has not been tested.
